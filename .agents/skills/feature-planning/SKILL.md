# Feature Planning Skill

## Objective

Produce an implementation plan before writing code.

## Workflow

### 1. Understand

Read the relevant documentation.

Identify:

- Business objective
- Actors
- User stories
- Acceptance criteria
- Business rules

### 2. Inspect

Inspect the existing codebase.

Identify:

- Related models
- Controllers
- Routes
- Views
- Migrations
- Tests

### 3. Analyze

Determine:

- Components that need modification
- New components required
- Database changes
- Validation requirements
- Authorization requirements
- Security considerations

### 4. Design

Propose:

- Implementation approach
- File structure
- Database changes
- Request/response flow
- Test scenarios

### 5. Present Plan

Provide:

- Feature overview
- Scope
- Technical approach
- Files to create or modify
- Implementation steps
- Acceptance criteria
- Risks and assumptions

## Constraints

- Do not modify files during planning.
- Do not invent business requirements.
- Clearly identify assumptions.
- Avoid unnecessary abstraction.
- Wait for explicit approval before coding.
