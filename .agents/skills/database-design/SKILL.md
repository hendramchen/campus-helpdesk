# Database Design Skill

## Objective

Design a consistent and maintainable relational
database schema.

## Guidelines

1. Understand business entities and relationships.
2. Identify primary and foreign keys.
3. Define appropriate column types.
4. Identify nullable and required fields.
5. Define unique constraints.
6. Identify appropriate indexes.
7. Consider referential integrity.
8. Consider data lifecycle and deletion behavior.
9. Follow existing naming conventions.

## Laravel Guidelines

- Use migrations for schema changes.
- Use Eloquent relationships.
- Use database constraints.
- Use seeders for reference data.
- Avoid storing redundant data without justification.

## Output

Before implementation, provide:

- Entity descriptions
- Table definitions
- Relationship descriptions
- Constraints and indexes
- Migration plan
- Potential data integrity risks

Do not modify the database during planning.
