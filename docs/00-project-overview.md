# Campus IT Helpdesk

## 1. Overview

Campus IT Helpdesk is a web-based application
that allows students to report IT-related
problems within the university.

The application helps organize, monitor,
and manage IT support requests.

## 2. Objectives

- Simplify IT problem reporting.
- Provide visibility into ticket progress.
- Organize problems by category and priority.
- Maintain a record of reported issues.

## 3. Target Users

- Students
- IT Support Staff

## 4. Technology Stack

- Backend: Laravel
- Frontend: Laravel Blade
- Database: MySQL
- Language: PHP

Verify exact versions against the existing
project configuration.

## 5. Project Scope

Included:

- Ticket listing
- Ticket creation
- Ticket detail
- Ticket status management

Excluded:

- Technician assignment
- Email notifications
- File attachments
- Analytics dashboard
